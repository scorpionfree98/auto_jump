## 安装与升级

- [x] 新安装能正常打开规则页，无崩溃。
- [x] 固定开发签名可覆盖安装，首次安装时间和应用配置保持不变。
- [x] 旧签名丢失时，先备份私有配置，再卸载、安装并恢复 `default_link` 成功。
- [ ] 从旧版升级后原规则存在，首次保存/导出变为 schema v3。
- [ ] 导出 JSON 后可覆盖导入和追加导入。
- [ ] 长按图标的“设置”能进入规则列表。
- [ ] Android 10+ 导出不申请全盘存储权限。

## 条件与普通动作

- [ ] 时间条件包含工作日、每天和跨午夜三种情况。
- [ ] WiFi 条件在授权/拒绝位置权限时结果符合预期。
- [ ] 蓝牙条件在 Android 12+ 授权/拒绝附近设备权限时结果符合预期。
- [ ] 充电与未充电条件分别验证。
- [ ] 位置条件使用有效缓存及无位置缓存两种情况。
- [ ] 多条件按 AND 匹配，多规则按优先级排序且全部执行。
- [ ] deeplink 打开成功；无人处理的 deeplink 显示失败状态。
- [ ] WAIT 不阻塞界面，并在等待后继续下一动作。

## 点击编辑与记录

- [x] 未开启无障碍服务时能看到明确状态和跳转入口。
- [ ] 编辑已有点击时取最近的前置 deeplink；新增点击没有前置 deeplink 时使用当前默认 deeplink。
- [ ] 录制跳转后仅在目标应用显示“开始录制/取消”无障碍悬浮窗。
- [ ] 点击“开始录制”之前的目标页面点击不会被捕获，开始按钮自身也不会被当作目标。
- [ ] 点击目标控件后正确回填包名、控件特征、坐标，以及从“开始录制”到目标点击的延迟。
- [ ] 捕获成功后自动返回点击编辑页；若系统限制后台跳转，手动返回仍能完成回填。
- [ ] 记录请求超过 5 分钟后过期。
- [ ] 密码框、文本输入框、系统设置、权限弹窗、锁屏和桌面均不会记录敏感内容。
- [ ] 编辑、删除、上移、下移后动作顺序正确并能持久化。
- [ ] 横竖屏或进程重建后草稿及待回填动作不串位。

## 点击执行

- [x] 应用内安全自检按 1 秒延迟点击，日志秒级时间与配置一致。
- [ ] 安全自检和规则测试运行全程不显示录制悬浮窗，不等待用户点开始。
- [x] 控件 ID 选择器在 AutoJump 自身专用目标上成功。
- [ ] 文字和描述选择器分别验证。
- [ ] 选择器失效但有坐标时使用坐标回退。
- [ ] 选择器失效且无坐标时在超时后失败，不点击其他位置。
- [ ] 前台应用包名不符时不执行，切回目标应用后在超时内可继续。
- [ ] 密码控件、禁用控件、系统界面和桌面不会被点击。
- [ ] “失败后继续”开启和关闭时后续动作行为正确。
- [ ] 多条会话同时存在时不串用目标或动作索引。

## 锁屏与恢复

- [ ] 规则未开启解锁选项时不会主动唤醒解锁页。
- [ ] 无安全锁/滑动锁：系统允许时可解除并继续动作。
- [ ] PIN/图案/密码：只显示系统认证，应用界面不接收凭据。
- [ ] 指纹/人脸：认证成功后恢复同一会话。
- [ ] 取消认证后任务保持等待，状态页可见且可清空。
- [ ] 屏幕旋转、切后台、锁屏再解锁后不会重复执行已完成动作。
- [ ] 重启设备后检查待执行会话是否符合预期；无障碍服务关闭时不执行点击。

## HyperOS 特项

- [ ] 默认省电策略下记录启动和点击是否被限制。
- [ ] 根据实际需求开启自启动/后台运行后再次验证。
- [ ] 后台弹出界面被系统禁止时，会话保留等待且日志给出说明。
- [x] 系统无障碍安全提示流程可完成，服务能正常绑定。
- [ ] 关闭服务后立即停止后续点击。
- [ ] 通知、来电、悬浮窗和分屏状态下不发生误点击。
