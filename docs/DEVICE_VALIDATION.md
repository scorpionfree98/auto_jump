## 点击执行

- [x] 普通点击日志只报告“点击指令/手势已发送”，不把 Android 派发回调表述为第三方业务成功。
- [ ] 安全自检和规则测试运行全程不显示录制悬浮窗，不等待用户点开始。
- [x] 控件 ID 选择器在 AutoJump 自身专用目标上成功。
- [ ] 文字和描述选择器分别验证。
- [x] 页面存在两个同名“打卡”时，使用录制坐标选择距离最近的候选，不误选底部导航。
- [x] 小程序文字节点的可点击父区域覆盖大半屏幕时，直接使用录制坐标手势，不对整页容器执行伪成功点击。
- [ ] 选择器失效但有坐标时使用坐标回退。

- [ ] “失败后继续”开启和关闭时后续动作行为正确。

## 锁屏与恢复

- [ ] 规则未开启解锁选项时不会主动唤醒解锁页。
- [ ] 无安全锁/滑动锁：系统允许时可解除并继续动作。
- [ ] PIN/图案/密码：只显示系统认证，应用界面不接收凭据。
- [ ] 指纹/人脸：认证成功后恢复同一会话。
- [ ] AutoJump 不再显示自有解锁说明/重试弹窗，透明跳板只请求系统认证（实现及自动测试完成，待真机锁屏回归）。
- [ ] 取消认证后任务保持等待并关闭透明跳板，之后解锁由原会话自动续跑（实现及自动测试完成，待真机锁屏回归）。
- [ ] 同一规则存在 PENDING/WAITING/RUNNING 会话时重复点击入口复用原会话，不重复入队（策略测试完成，待真机入口回归）。
- [ ] 屏幕旋转、切后台、锁屏再解锁后不会重复执行已完成动作。
- [ ] 重启设备后检查待执行会话是否符合预期；无障碍服务关闭时不执行点击。
