# 锁屏触发亮屏设计

## 目标

规则在熄屏且安全锁屏时触发，Auto Jump 应立即点亮屏幕并进入 Android 系统认证；用户完成指纹、PIN 或图案认证后，原执行会话自动继续。应用不保存或模拟认证凭据。

## 方案

采用系统 `PowerManager.WakeLock` 的限时亮屏能力，并保留现有透明 `UnlockGateActivity`。编排器只有在规则启用了“锁屏时请求系统解锁”且系统确认当前锁屏时才进入该路径。亮屏控制器仅在屏幕不处于交互状态时申请亮屏锁，并设置固定超时，防止异常流程长期耗电；透明活动继续使用 `setTurnScreenOn` 和 `requestDismissKeyguard` 完成系统认证衔接。

不采用无障碍录制密码、ADB 解锁或设备管理器重置锁屏。这些方式既不能稳定跨越 Android 安全边界，也会引入凭据泄露风险。

## 状态流

1. 规则入队并检测到 Keyguard 锁定。
2. 若屏幕已熄灭，申请限时亮屏锁；若锁屏界面本来已亮，不重复持锁。
3. 启动透明解锁活动，由 Android 显示指纹/PIN/图案界面。
4. 认证成功后恢复原 session；取消后保留 session，等待之后的解锁事件续跑。
5. WakeLock 到时由系统自动释放，不影响后续自动熄屏。

## 验证

- JVM 单元测试覆盖“熄屏时唤醒、已亮屏不重复唤醒”和超时范围。
- Android Lint、全量 JVM 测试、Debug APK 构建通过。
- 小米 14 Pro 锁屏实测：触发后亮屏；认证后打开飞书并继续点击动作。
